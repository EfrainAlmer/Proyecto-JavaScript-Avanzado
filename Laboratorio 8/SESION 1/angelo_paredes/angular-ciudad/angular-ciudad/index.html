Angular es una ciudad

Una app Angular se entiende mejor como una ciudad: tiene calles para moverse, edificios para vivir, tuberías que transforman lo que pasa por ellas y ventanillas donde la gente entrega datos. Toca cada pestaña y prueba cada elemento.

Navegación (Router)

En la ciudad: el mapa del metro

En palabras simples: el Router decide qué pantalla mostrar según la dirección (URL) del navegador. Si escribes /menu, muestra la pantalla del menú. Todo pasa sin que la página se recargue.

El Router une una URL con un componente. Cambias de "estación" sin recargar la página: es una SPA (Single Page Application). Haz clic en una estación.

// app.routes.ts
export const routes: Routes = [
  { path: '',         component: InicioComponent },
  { path: 'menu',     component: MenuComponent },
  { path: 'pedido/:id', component: PedidoComponent },
  { path: '**',       component: NoEncontradoComponent }
];

<a routerLink="/menu">Ver menú</a>
<router-outlet />   <!-- aquí aparece la vista -->

Componentes

En la ciudad: los edificios

En palabras simples: un componente es una pieza de la pantalla (un botón, una tarjeta, un menú). La creas una sola vez y la puedes repetir todas las veces que quieras, cada una con datos distintos.

Un componente es una pieza reutilizable: HTML (lo que se ve), CSS (cómo se ve) y TypeScript (qué hace). Se escribe una vez y se usa muchas veces, cambiando sus @Input. Añade edificios:

@Component({
  selector: 'app-tienda',
  standalone: true,
  template: `<h3>{{ icono }} {{ nombre }}</h3>`,
  styles: [`h3 { color: #DD0031 }`]
})
export class TiendaComponent {
  @Input() nombre = '';
  @Input() icono = '';
}

<app-tienda nombre="Panadería" icono="🥖" />

Pipes

En la ciudad: las tuberías de la planta de agua

En palabras simples: un pipe cambia cómo se ve un dato, sin tocar el dato original. Por ejemplo, mostrar un texto en mayúsculas o un número como dinero.

Un pipe transforma un dato solo para mostrarlo, sin cambiar el original. Se pueden encadenar con |. Activa tuberías y mira cómo cambia el resultado.

{{ nombre | uppercase }}
{{ precio | currency:'PEN' }}
{{ fecha  | date:'dd/MM/yyyy' }}

// Pipe propio
@Pipe({ name: 'saludo', standalone: true })
export class SaludoPipe implements PipeTransform {
  transform(v: string) { return '¡Hola, ' + v + '!'; }
}

Formularios

En la ciudad: la ventanilla de trámites

En palabras simples: un formulario sirve para que el usuario escriba datos. Angular revisa que sean correctos (por ejemplo, que el correo tenga @) y bloquea el botón si algo falla.

Los formularios recogen datos y los validan antes de enviarlos. Angular sigue el estado de cada campo (válido, tocado, con error). Prueba a enviar uno incompleto.

form = new FormGroup({
  correo: new FormControl('', [Validators.required, Validators.email]),
  clave:  new FormControl('', [Validators.required, Validators.minLength(6)])
});

<form [formGroup]="form" (ngSubmit)="enviar()">
  <input formControlName="correo">
  <button [disabled]="form.invalid">Enviar</button>
</form>

Mini glosario

SPA: aplicación web que cambia de pantalla sin recargar la página.
URL: la dirección que ves arriba en el navegador.
Selector: el nombre de la etiqueta de un componente, por ejemplo <app-tienda>.
@Input: un dato que le pasas a un componente desde afuera.
Template: la parte HTML de un componente.
Validación: revisar que lo que escribió el usuario sea correcto.
TypeScript: el lenguaje en el que se programa Angular (es JavaScript con tipos).
